# Producto Integrador – El Final del Proceso

Sitio web desarrollado como evidencia final del curso **Proyecto II**, donde se documenta el proceso de desarrollo del sistema **Residencial Los Robles** mediante la metodología **Scrum**.

El proyecto reúne las actividades realizadas durante el curso, la implementación del sistema, el código fuente, el reporte de modificaciones y el acceso al repositorio del proyecto.

## Objetivo

Presentar de forma organizada la documentación final y el producto desarrollado durante el proceso del curso, integrando evidencias técnicas y funcionales del sistema implementado.

## Contenido del sitio

El sitio incluye las siguientes secciones:

### Actividades realizadas en el curso
Se presentan las evidencias en formato PDF correspondientes a las actividades desarrolladas durante la materia, relacionadas con:

- Scrum
- Sprint Schedule
- Product Backlog
- Desarrollo iterativo
- Revisiones del proyecto
- Ajustes y modificaciones
- Producto final

### Sistema implementado
Se documenta el sistema **Residencial Los Robles**, una plataforma web orientada a la gestión comunitaria de una colonia residencial.

El sistema busca resolver problemáticas relacionadas con:

- Gestión de residentes
- Registro y consulta de pagos
- Comunicación mediante anuncios
- Servicios de emergencia
- Organización comunitaria

Se incluyen capturas de pantalla del funcionamiento del sistema y descripción de sus principales módulos.

### Código fuente
Se proporciona el código fuente comprimido del proyecto desarrollado.

### Reporte de modificaciones
Se incluye un documento con las mejoras y ajustes implementados durante el desarrollo del sistema.

### Repositorio GitHub del sistema
Repositorio del proyecto:

**Residencial Los Robles**  
https://github.com/ElAlets/residencial-los-robles
